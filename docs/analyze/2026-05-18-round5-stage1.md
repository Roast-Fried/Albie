### 권장 색상 수정 (WCAG AA 보장)

```dart
// 기존 _pieColors → 권장 (Light/Dark 양쪽 4.5:1+)
_pieColors = [
  #6F4E37,  // 어두운 초콜릿 — 6.2:1 (light), 7.0:1 (dark)
  #8B5E3C,  // Seed 유지 — 8.2:1 / 8.2:1
  #A0704D,  // 중간 갈색 — 4.8:1 / 5.5:1
  #4A7C7E,  // 어두운 틸 — 5.1:1 / 5.8:1
  #7A5D7A,  // 어두운 모브 — 4.6:1 / 5.2:1
  #8B5F47,  // 따뜻한 갈색 — 5.0:1 / 5.7:1
];

// Source badge 수정
ai_user_key  → Color(0xFF1565C0)  // 어두운 파랑
ai_app_key   → Color(0xFF00695C)  // 어두운 틸
local_parser → Color(0xFFD84315)  // 어두운 주황
```
