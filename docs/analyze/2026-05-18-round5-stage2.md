## Domain 2: Agent B (WCAG contrast) 수치 정확성 검증

### WCAG 계산 공식

```
sRGB 정규화: s = channel / 255
gamma 보정: linear = s/12.92 (s<=0.04045), ((s+0.055)/1.055)^2.4 (s>0.04045)
L = 0.2126*R_lin + 0.7152*G_lin + 0.0722*B_lin
Contrast = (L_lighter + 0.05) / (L_darker + 0.05)
```

---

### 2a. Pie Chart #D4A574 위 흰색 텍스트 — 2.0:1 주장 검증

**원 주장:** white on #D4A574 → 2.0:1

**계산:**
```
#D4A574: R=212, G=165, B=116
sRGB: 0.831, 0.647, 0.455
R_lin = ((0.831+0.055)/1.055)^2.4 = 0.840^2.4 ≈ 0.677
G_lin = ((0.647+0.055)/1.055)^2.4 = 0.665^2.4 ≈ 0.385
B_lin = ((0.455+0.055)/1.055)^2.4 = 0.483^2.4 ≈ 0.197
L = 0.2126*0.677 + 0.7152*0.385 + 0.0722*0.197
  = 0.144 + 0.275 + 0.014 = 0.433
Contrast = 1.05 / (0.433+0.05) = 1.05/0.483 ≈ 2.17:1  → FAIL (4.5:1 미달)
```

**Verdict: NEEDS_RECALCULATION**
- 2.0:1 → 실측 2.17:1. 방향은 맞으나 수치 부정확. FAIL 결론 동일.

**핵심 구조적 오류:** _pieColors는 Material ColorScheme.fromSeed 파생이 아닌 stats_screen.dart에 hard-coded. Material 3가 선택한 색이라는 framing은 오류. WCAG fail 결론은 유효하나 수정 경로는 ColorScheme이 아닌 _pieColors 배열 직접 수정.

### 2b. Source Badge Colors.orange Light/Dark — 대비율 검증

**원 주장:** dark mode source badge orange → 2.8:1 FAIL

**Colors.orange = #FF9800**

```
R_lin = 1.0 (255/255)
G_lin = ((0.596+0.055)/1.055)^2.4 = 0.617^2.4 ≈ 0.331
B_lin = 0.0
L(FF9800) = 0.2126 + 0.7152*0.331 = 0.2126+0.2367 = 0.449

Light mode (흰 배경): Contrast = 1.05/(0.449+0.05) = 1.05/0.499 ≈ 2.10:1  → FAIL
Dark mode (#121212): L ≈ 0.005
  Contrast = (0.449+0.05)/(0.005+0.05) = 0.499/0.055 ≈ 9.07:1  → PASS
```

**Verdict: NEEDS_RECALCULATION**
- Light mode FAIL: 방향 맞음 (약 2.10:1).
- Dark mode: Agent B 2.8:1 FAIL → 실측 약 9.07:1 **PASS**.
- **Agent B의 dark mode fail 주장은 오류.** #121212 배경에서 orange는 충분한 대비를 가짐.

### 2c. withValues(alpha: 0.15) 블렌딩 후 실제 색상 및 대비율

**원 주장:** alpha 0.15 적용 후에도 contrast fail

**alpha=0.15 블렌딩 계산 (흰 배경):**
```
R = 255*0.15 + 255*0.85 = 255
G = 152*0.15 + 255*0.85 = 22.8 + 216.75 = 239.55 ≈ 240
B = 0*0.15   + 255*0.85 = 216.75 ≈ 217
블렌딩 배경색 = #FFF0D9 (매우 연한 복숭아색)

L(FFF0D9) ≈ 0.88 (매우 밝음)
검정 텍스트 on #FFF0D9: (0.88+0.05)/(0+0.05) = 0.93/0.05 = 18.6:1  → PASS
orange 텍스트 on #FFF0D9: (0.88+0.05)/(0.449+0.05) = 0.93/0.499 ≈ 1.86:1  → FAIL
```

**Verdict: NEEDS_RECALCULATION**
- 배지 배경에 alpha 0.15가 적용되면 배경이 매우 밝아짐.
- 어두운 텍스트(검정/진한 갈색)을 쓰면 18.6:1로 PASS — Agent B 주장과 반대.
- Badge 텍스트 색이 orange 계열이라면 1.86:1 FAIL. 실제 badge 텍스트 색 확인 후 최종 판정 필요.
