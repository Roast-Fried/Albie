## Medium Issues

### SEC-001 — main.dart crash handler 의 stack trace debugPrint
- **severity**: medium
- **file**: [lib/main.dart:25,31,49](lib/main.dart#L25)
- **description**: `details.stack` / `stack.toString()` 을 `debugPrint` 로 출력. Flutter `debugPrint` 는 release 모드에서도 dev console 에 출력됨 (kReleaseMode 분기 없음). 만약 stack trace 안에 Gemini API key 나 사용자 입력 PII 가 포함되면 잠재적 노출.
- **mitigation**: stack trace 는 일반적으로 코드 위치만 담아 PII 가능성 낮음. 그러나 보수적 처리 권장 — `if (kReleaseMode) return;` 로 release 에서 console 출력 차단하거나, Sentry/Crashlytics 같은 안전 채널로 전송.
- **autoFixable**: yes (release 분기 추가)
