# 강의 필기 요약 — Dart/Flutter 기초 이론

> 필기고사 대비 (강의 전사 .txt 기반). 코드 실행 결과/개념 중심.

## 1. Dart 기초
- **변수**: `var`(타입추론), `final`(런타임 1회), `const`(컴파일 상수), `dynamic`(타입 우회).
- **Null safety**: `T?`(nullable), `?.`(null이면 단락), `??`(null 대체), `??=`(null일 때 할당), `!`(non-null 단언).
- **연산자**: 산술 `~/`(정수나눗셈) `%`, 논리 `&& || !`, 캐스트 `as`, 타입검사 `is`/`is!`, cascade `..`, spread `...`/`...?`.
- **문자열 보간**: `'$x'`, `'${expr}'`.

## 2. 제어문 & 함수
- if/else, switch(Dart3 패턴매칭 + `when` guard), for/for-in, while/do-while, break/continue.
- 함수: 위치/선택([]) /명명({}) 매개변수, `required`, 기본값, 화살표 `=>`, `typedef`.

## 3. OOP
- class/생성자(`this.x` 단축), named constructor, `factory`.
- `final` 필드 + `const` 생성자 = 불변. getter/setter(`get`/`set`).
- 상속 `extends`/`super`, `@override`, `implements`(인터페이스), `abstract`, `mixin with`.
- 동등성 `==` + `hashCode`, 캡슐화 `_`(라이브러리 private).

## 4. 함수형
- `map`(변환), `where`(필터), `reduce`(동일타입 집계), `fold`(다른타입 집계, 초기값), `toList/toSet`.
- 모두 **새 컬렉션 반환**(원본 불변).

## 5. 비동기
- `Future<T>`: `.then()` / `async`+`await`. `Future.delayed`.
- `Stream<T>`: 여러 값, `.listen()`, `async*`+`yield`.
- **FutureBuilder**: `future:` + `builder(context, snapshot)`. `snapshot.connectionState`(waiting/done), `hasData`/`hasError`. setState 시 future 재실행.
- **StreamBuilder**: `stream:` + snapshot. connectionState(none/waiting/active/done).

## 6. Widget
- **StatelessWidget**(불변) vs **StatefulWidget**(State 가변).
- **Lifecycle**: `createState` → `initState`(1회 초기화, context 미완성) → `didChangeDependencies` → `build`(여러번) → `didUpdateWidget`(부모 갱신) → `dispose`(정리). `setState`로 dirty→rebuild.
- **레이아웃**: Container(box model), Row/Column(main/crossAxisAlignment), Expanded/Flexible(flex), Stack/Positioned, Padding(EdgeInsets), SizedBox, Center, Wrap.
- **표시/입력**: Text(TextStyle), ElevatedButton(onPressed), GestureDetector(onTap), ListView.builder(itemCount/itemBuilder), Scaffold(appBar/body/FAB).

## 7. Navigation
- `Navigator.push(MaterialPageRoute)` / `pop([result])` / `pushReplacement` / `pushAndRemoveUntil` / `popUntil`.
- Named Routes: `routes:{}` + `pushNamed`. **onGenerateRoute**(권장): `settings.name` switch + `settings.arguments` 타입검증 + 에러페이지 fallback. 경로 상수화로 오타 방지.
- 뒤로가기: WillPopScope(deprecated)→**PopScope**(`canPop`/`onPopInvoked`).

## 8. 데이터 저장
- **SharedPreferences**: key-value. `getInstance` → `setString/getString` 등. 설정/플래그 저장용.
- **Drift**: 반응형 SQLite ORM. Table 정의 + `build_runner` 코드생성 + DAO + `watch()`(Stream) + `schemaVersion` 마이그레이션. StreamBuilder 와 결합해 실시간 UI.

## 9. 개발 방법론 (AI 시대)
- 개발 = 코드 작성만이 아니다(기획→디자인→개발→테스트).
- **SDD**(스펙 우선) / TDD(테스트 우선) / DDD(도메인 우선). 강의는 SDD 권장.
- AI 디자인: Stitch(초안) → Claude Design(정제) → Figma → 코드. AI가 기획을 타협시키지 말 것.
