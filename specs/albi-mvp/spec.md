# Albi MVP — Specification (SDD)

> Spec-Driven Development 산출물. 강의 "Spec-Kit(SDD)" 단원 대응.
> 원천: `docs/기획서.md` (외부 기획서 v2.1 통합본). 본 문서는 그 canonical spec 형태.

## 1. 개요 (Composition / MVP)

**알비(Albi, 알코올 비서)** — 한 줄 자연어로 음주를 기록하는 모바일 앱.

- 한 줄("어제 강남에서 글렌피딕 두 잔") → 구조화된 음주 기록 초안 생성.
- AI(Gemini) 연결 시 정밀 파싱, 미연결 시 로컬 규칙 파서 fallback (AI 없어도 동작).
- **자동 저장 금지** — 반드시 검토/수정 화면을 거쳐 저장.

## 2. 타깃 / 가치

- 술을 즐기지만 기록이 번거로운 사용자.
- 가치: (1) 마찰 없는 입력(자연어) (2) 마셔본 술 아카이브·테이스팅 노트 (3) 음주 패턴 통계.

## 3. User Stories

1. 사용자로서 한 줄 자연어로 음주를 입력하면 술/수량/도수/장소/날짜가 자동 분해된 초안을 받고 싶다.
2. 저장 전 초안을 검토·수정하여 잘못된 파싱을 바로잡고 싶다.
3. 마셔본 술의 향·맛·평점을 테이스팅 노트로 남기고 싶다.
4. 마셔본 술을 아카이브에서 집계·즐겨찾기로 다시 보고 싶다.
5. 월별/기간별 음주 통계를 차트로 보고 싶다.
6. AI 키가 없어도 앱이 동작하길 원한다.
7. (강의 추가) 음주 다음날 컨디션(숙취/수면)을 기록해 패턴을 보고 싶다.

## 4. 기능 요구사항

### 4.1 핵심 (MVP 필수)
| # | 기능 | 수용 기준 |
|---|------|-----------|
| F1 | AI 연결 관리 | 기본 제한형/개인 Key + 모델 선택, secure storage 저장 |
| F2 | 자연어 기록 입력 | 한 줄 → 초안. AI 미연결 시 로컬 파서 fallback |
| F3 | 기록 검토·수정·저장 | 검토 화면 필수(자동저장 금지), sqflite 트랜잭션 CRUD |
| F4 | 테이스팅 노트 | 향/맛/피니시/평점/감상 수동 작성 |
| F5 | 마셔본 술 아카이브 | 집계 + 즐겨찾기 + 재기록 |

### 4.2 선택 (구현 완료)
음식 태그 · 사진 첨부 · AI 이미지 보조 · AI 노트 보완 · 업적 · 음주 캘린더 · 클라우드 백업(opt-in) · 리스트 애니메이션 · 로컬 알림.

### 4.3 강의 정합 추가 (2026-06-04 본 SDD 사이클)
| # | 기능 | 수용 기준 |
|---|------|-----------|
| F6 | 컨디션 로그 (Drift 데모) | 숙취/수면/메모 기록, Drift watch()+StreamBuilder reactive, 메인 sqflite와 격리 |

## 5. 화면 (15 `*_screen.dart`)
온보딩 · 홈 · 초안검토 · 기록목록/상세 · 아카이브목록/상세 · 통계 · 캘린더 · 설정/AI설정/알림설정/계정 · 더보기 · 라우트에러 · **컨디션로그(신규)**.

## 6. 범위 제외 (Out of Scope)
- 소셜/공유, 다중 사용자 계정 체계(클라우드는 단일 사용자 백업만), 웹/데스크톱 정식 지원, 결제.

## 7. 비기능 요구사항
- **failure path first**: AI 실패/취소/네트워크 오류/DB 오류 복구 경로 우선 설계.
- **개인정보**: 단건 삭제 시 parseJob 원문 NULL, 전체 삭제 시 행 삭제.
- **오프라인 동작**: AI/클라우드 없이 로컬만으로 전 기능 동작.
- **접근성**: 터치 타깃 48dp, WCAG AA 대비, Semantics 라벨.
